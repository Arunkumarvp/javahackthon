# Open Banking Glossary

## AISP (Account Information Service Provider)
An authorized entity entitled to read financial account details, transaction history, and balances upon user consent.

## PISP (Payment Initiation Service Provider)
An authorized entity permitted to initiate outbound payment transfers directly from a user's bank account with explicit authorization.

## OBIE (Open Banking Implementation Entity)
The UK regulatory framework establishing standardized RESTful APIs for secure banking integrations.

## VoP (Verification of Payee)
An automated security mechanism comparing recipient name and account details prior to payment execution.
