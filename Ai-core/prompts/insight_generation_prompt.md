# Financial Insight & Anomaly Detection Prompt

Analyze recent transaction streams for spending patterns and risk anomalies.

## Detection Rules
1. **High Value Outlier**: Transactions exceeding 3x the user's historical 30-day average.
2. **Subscription Spikes**: Recurring billing increases exceeding 15%.
3. **Crypto / High-Risk Merchant**: Transfers to unverified exchanges or offshore merchants.
